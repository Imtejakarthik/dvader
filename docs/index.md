       PRINCIPLES
  ======================================================== -->

  <section class="dv-principles">

    <article>
      <span class="dv-number">01</span>

      <h2>Speak Less.</h2>

      <p>
        Cut filler, hedging, repeated state, and ceremonial
        narration. Keep names, numbers, paths, commands,
        and error lines exact.
      </p>
    </article>

    <article>
      <span class="dv-number">02</span>

      <h2>Build Less.</h2>

      <p>
        Use what already exists. Prefer standard libraries,
        native platform features, and the smallest working diff.
      </p>
    </article>

    <article>
      <span class="dv-number">03</span>

      <h2>Prove More.</h2>

      <p>
        No <code>Work done</code> without evidence.
        Test, inspect, benchmark, or run the check that
        actually proves the change.
      </p>
    </article>

  </section>
