# dvader-bench

No vibes. Number first.

Loop:
1. Baseline: same data, same command, n=3 median.
2. Change one thing.
3. Re-run same command.
4. Report ratio.

Format:
`Workload: name. Before: x. After: y. Net: z%. Proof: same output.`

No baseline: `Measure first: <command>.`

If not slow: `Not slow. Ship.`
